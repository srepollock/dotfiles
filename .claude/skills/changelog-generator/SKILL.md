---
name: changelog-generator
description: Generate or append to a CHANGELOG.md file with all relevant commits.
---

Generate or add to the CHANGELOG.md file. This should be run after the update-version skill to update the changelog. The most recent version should be at the top of the file, and the last recorded version at the end (so users can see the latest first). Relevant commits should be included per version. Please use the general best practices for a CHANGELOG.md file.
