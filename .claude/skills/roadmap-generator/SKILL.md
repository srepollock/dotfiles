---
name: roadmap-generator
description: Generate a ROADMAp.md based on the current github project, issues, milestones and project goals.
---

Generate a ROADMAP.md file for the project. This file is generated based on:

1. The overall project goal
2. Github Milestones
3. Github Issues
4. Github Project plans

We want this file to include the general idea for when project features will be implemented and added. Dates are fine to include, but generally it should show features/bug added by version.
